# MyWayInSpain — Логіка проекту (v1.0)

> Кредитний і грантовий брокер в Іспанії (Аліканте / Comunitat Valenciana).
> Сайт = машина генерації лідів. Скоринг = безкоштовний гачок. Монетизація = консультації та супровід.

---

## 1. Сегменти користувачів

| # | Сегмент | Біль клієнта | Що дає сайт |
|---|---------|--------------|-------------|
| 1 | **Фізичні особи** | Не знає, чи дадуть кредит; банки відмовляють | Прескоринг: споживчі кредити, автокредити та інші популярні форми кредитування. **Іпотека — НЕ входить (поки що)** |
| 2 | **Autónomo / МСП** ⭐ ПРІОРИТЕТ | Не розуміє, які фінансування доступні (ICO, мікрокредити, банки) | Скоринг + підбір інструментів фінансування |
| 3 | **Гранти / інвестиції** | Не знає про субсидії (Kit Digital, IVACE, ENISA...) | Матчинг з грантовими програмами за профілем |

## 2. Воронка (основна логіка)

```
Лендинг → Вибір сегмента (1/2/3)
   ↓
Анкета (10–20 питань, покроково)
   ↓
СКОРИНГ (розрахунок на сервері)
   ↓
Результат: категорія A/B/C + 2–3 загальні рекомендації (безкоштовно)
   ↓
🔒 Повний розбір = платна консультація (від €49 + IVA)
   ↓
Лід → Supabase (панель) + сповіщення в Telegram
   ↓
Запис на консультацію ТІЛЬКИ після оплати
   ↓
Консультація: МІНІМУМ 2 шляхи вирішення питання
   ↓
Продаж пакета (документи / супровід / аналітика)
```

### Категорії скорингу
- **A (зелений)** — висока ймовірність схвалення
- **B (жовтий)** — можливо, з умовами
- **C (червоний)** — зараз ні, але є план дій → теж лід (консультація "план виправлення")

## 3. Монетизація

- **Скоринг:** безкоштовно (гачок).
- **Консультації:** платні, "від €49 + IVA". Без оплати консультація НЕ призначається.
- **Експрес-консультація зараховується** у вартість пакета при подальшій співпраці.
- **Супровід "під ключ":** модель **фікс + success fee**. Фікс зараховується в пакет при співробітництві.
- Деталі: див. `SERVICES_PRICING.md`.

## 4. Мови сайту (i18n)

7 мов: **ES** (основна), **UK**, **RU**, **PL**, **DE**, **FR**, **EN**.

Рекомендація з фазування контенту:
- **Фаза 1 (MVP):** ES + UK + EN — повний контент
- **Фаза 2:** RU + PL
- **Фаза 3:** DE + FR

Архітектура i18n закладається одразу під усі 7 мов (next-intl / route-based locales).

## 5. Ліди та інтеграції

- **Зберігання лідів:** Supabase (контакт, сегмент, відповіді анкети, скоринг-результат, статус).
- **Сповіщення:** Telegram-бот шле повідомлення про новий лід.
- **Telegram-бот (підключений до лендингу), функції:**
  1. Фіксація лідів
  2. Запис на консультацію
  3. Фіксація оплати (підтвердження → консультація призначається)
- **Оплата:** по домовленості (рахунок / Bizum / переказ). Stripe — опційно пізніше. Правило: **немає оплати → немає консультації**.

## 6. Юридична частина

- **RGPD (GDPR):** згода на обробку даних, політика конфіденційності, оператор даних — autónomo (Santa Pola).
- **Дисклеймер скорингу:** "це попередня оцінка, а не офіційне кредитне рішення банку".
- Cookies-банер (мінімальні за замовчуванням).
